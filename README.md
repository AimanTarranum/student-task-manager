# student-task-manager
a task manager for students subtle, soft-pink aesthetic, thoughtfully designed to blend elegant visuals with seamless functionality, making academic organization both intuitive and enjoyable.
About the Project

Student Task Manager is a beginner-friendly web application developed using HTML, CSS, and JavaScript. It allows students to add, edit, delete, and organize their tasks in one place.

The application also provides a progress tracker to help students monitor completed and pending tasks.

 Features

Add Tasks: Create tasks with a name, deadline, and priority.

Edit Tasks: Update existing task details.

Delete Tasks: Remove tasks when they are no longer needed.

Mark as Completed: Track finished tasks using checkboxes.

Search Tasks: Find tasks by their names.

Filter Tasks: View all, pending, or completed tasks.

Sort Tasks: Arrange tasks by earliest or latest deadline.

Overdue Highlighting: Identify tasks with missed deadlines.

Progress Tracking: View total, completed, and pending tasks with a progress bar.

Local Storage: Automatically save tasks in the browser, even after refreshing the page.

Responsive Design: Use the application on desktop and mobile screens.
